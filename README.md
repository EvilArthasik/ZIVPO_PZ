# TraySampleApp

Win32-приложение в трее и Windows-служба, которые взаимодействуют через локальный Windows RPC (`ncalrpc`).

## Что реализовано

- Windows-служба `TraySampleService.exe` запускает GUI `TraySampleApp.exe` в пользовательских сессиях.
- GUI при запуске получает через RPC состояние текущего пользователя.
- Если пользователь не вошел, показывается форма входа, а антивирусная функциональность заблокирована.
- Служба выполняет HTTPS-запросы к backend API:
  - `POST /api/auth/login`
  - `POST /api/auth/refresh`
  - `POST /api/licenses/activate`
  - `POST /api/licenses/check`
- Access/Refresh JWT и лицензионный тикет хранятся только в оперативной памяти службы.
- GUI не получает JWT-токены и лицензионный тикет, только безопасное состояние: пользователь, наличие лицензии, дата истечения.
- Служба периодически обновляет токены и лицензионный тикет по срокам их действия.
- При выходе из аккаунта служба очищает токены и лицензию.
- При отсутствии, истечении или блокировке лицензии антивирусная функциональность блокируется.
- GUI периодически опрашивает состояние лицензии и обновляет главный экран.

## Антивирусный движок

- После запуска службы и после успешной активации продукта служба загружает антивирусные базы в оперативную память.
- База хранится как `std::map<uint64_t, std::vector<AvRecord>>`, где ключом являются первые 8 байт сигнатуры.
- Каждая запись базы содержит:
  - `ObjectSignaturePrefix` — первые 8 байт сигнатуры;
  - `ObjectSignatureLength` — длину полной сигнатуры;
  - `ObjectSignature` — SHA-256 хеш полной сигнатуры;
  - `OffsetBegin` и `OffsetEnd` — допустимый диапазон смещения в файле;
  - `ObjectType` — тип объекта (`PE` или `Script`);
  - `AvRecordSignature` — SHA-256 подпись всех полей записи, кроме самой подписи.
- Движок сканирования принимает абстракцию `IByteStream`, читает файл с позиции 0, ищет первые 8 байт в дереве базы и затем выполняет проверки от дешевых к дорогим: тип объекта, диапазон смещения, чтение хвоста сигнатуры, расчет SHA-256 и сравнение хеша.
- Реализовано сканирование выбранного файла и выбранной директории.
- Реализованы дополнительные функции: сканирование всех несъемных дисков, сканирование по расписанию и мониторинг выбранных директорий.
- Через RPC зарегистрированы методы получения информации об антивирусных базах, сканирования файла, директории, всех несъемных дисков, настройки расписания и настройки мониторинга.
- GUI отображает дату выпуска антивирусных баз и количество записей, запускает сканирование файла, папки и всех дисков, а также настраивает расписание и мониторинг.

Демонстрационные сигнатуры в базе:

- `Demo.EICAR.Script`: префикс `X5O!P%@A`, тип `Script`, диапазон смещения `0..4096`.
- `Demo.PE.TestSignature`: префикс `MZTRAYAV`, тип `PE`, диапазон смещения `0..1048576`.

## Сборка

```powershell
cmake -S . -B build -G "Visual Studio 17 2022" -A x64
cmake --build build --config Release
```

Исполняемые файлы:

- `build\Release\TraySampleApp.exe`
- `build\Release\TraySampleService.exe`

## Запуск

Backend должен быть запущен по HTTPS:

```text
https://localhost:8080
```

Установка и запуск службы выполняются из PowerShell от имени администратора:

```powershell
cd build\Release
.\TraySampleService.exe /install
Start-Service TraySampleService
```

Удаление службы:

```powershell
.\TraySampleService.exe /uninstall
```

## Проверка

1. При первом запуске GUI показывает форму входа.
2. При неверном логине или пароле показывается ошибка, функциональность остается заблокированной.
3. После успешного входа отображается имя пользователя.
4. Если лицензии нет, показывается форма ввода кода активации.
5. При неверном коде активации показывается ошибка, форма активации остается открытой.
6. После успешной активации отображаются дата окончания лицензии, дата выпуска антивирусных баз и количество записей.
7. Кнопка сканирования файла позволяет выбрать файл и получить результат проверки.
8. Кнопка сканирования папки запускает рекурсивную проверку выбранной директории.
9. Кнопка сканирования дисков запускает проверку всех несъемных дисков.
10. Кнопка расписания включает периодическое сканирование раз в 60 минут.
11. Кнопка мониторинга позволяет выбрать директорию, новые и измененные файлы в которой будут проверяться службой.
