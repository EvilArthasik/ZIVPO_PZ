# TraySampleApp

Win32-приложение с иконкой в области уведомлений и Windows-службой, которая запускает это приложение во всех пользовательских терминальных сессиях.

## Что реализовано

- GUI-приложение `TraySampleApp.exe` работает в трее и поддерживает скрытый запуск.
- Windows-служба `TraySampleService.exe` устанавливается ключом `/install` и удаляется ключом `/uninstall`.
- Служба запускает GUI во всех сессиях, кроме session 0, от имени владельца сессии.
- Служба отслеживает новые входы пользователей и подключения терминальных сессий.
- Сигналы SCM `Stop` и `Shutdown` не принимаются; остановка выполняется через Windows RPC.
- RPC использует локальный транспорт `ncalrpc` (ALPC) и интерфейс `TrayControl`.
- Пункты `Выход` в главном меню и меню трея отправляют RPC-команду остановки службы.
- При остановке службы завершаются все запущенные экземпляры GUI.
- При ручном запуске GUI проверяет состояние службы: если она остановлена, запускает ее, дожидается `Running` и завершает работу.
- GUI продолжает работу только если родительским процессом является `TraySampleService.exe`.
- Перед RPC-остановкой служба запрашивает подтверждение в активной терминальной сессии.
- Служба настраивает DACL своего процесса и дочерних GUI-процессов, запрещая открытие новых handles с правом `PROCESS_TERMINATE`.

Ограничение: DACL-защита препятствует обычному завершению процесса через `TerminateProcess`/диспетчер задач, но администратор с достаточными привилегиями Windows теоретически может изменить владельца/DACL или использовать отладочные привилегии. Полная защита от администратора требует специальных механизмов Windows Protected Process/драйвера и не реализуется обычной Win32-службой.

## Сборка

```powershell
cmake -S . -B build -G "Visual Studio 17 2022" -A x64
cmake --build build --config Release
```

После сборки исполняемые файлы находятся в каталоге `build`:

- `TraySampleApp.exe`
- `TraySampleService.exe`

## Установка и запуск службы

Команды нужно выполнять в PowerShell от имени администратора:

```powershell
.\build\TraySampleService.exe /install
Start-Service TraySampleService
```

Удаление службы:

```powershell
# Сначала остановите службу через пункт "Выход" в GUI-приложении.
.\build\TraySampleService.exe /uninstall
```

Так как обработка `Stop` отключена по требованию задания, штатная остановка выполняется через пункт `Выход` в GUI-приложении.
