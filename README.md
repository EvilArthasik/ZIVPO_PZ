# TraySampleApp

Пример Win32-приложения под Windows, которое:

- добавляет иконку в трей при запуске;
- показывает главное окно по левому клику по иконке;
- показывает контекстное меню по правому клику;
- скрывает окно при обычном закрытии и продолжает работать в фоне;
- завершает работу по команде `Выход` из трея или меню `Файл -> Выход`;
- повторно добавляет иконку после пересоздания панели задач (`TaskbarCreated`);
- поддерживает скрытый запуск (`/hidden`);
- запрещает второй запуск для того же пользователя через именованный mutex;
- собирается через CMake и может быть запущено в CI.

## Сборка локально

```powershell
cmake -S . -B build -G "Visual Studio 17 2022" -A x64
cmake --build build --config Release
```

## Запуск в скрытом режиме

```powershell
.\build\Release\TraySampleApp.exe /hidden
```
